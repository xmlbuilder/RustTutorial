# Rust Tutorial — Chapters

### 📌 Rust Tutorial for System & Engineering Developers
- Rust 학습을 위한 실전 중심 튜토리얼입니다.  
- 기초 문법부터 고급 패턴, 디자인 패턴, 프로젝트 예제까지 폭넓게 다룹니다.
- 이 저장소는 단순한 Rust 문법 입문서가 아닙니다.
- C/C++ 기반 개발자, 엔지니어, 보안·성능을 중시하는 개발자를 위해
  Rust의 설계 철학과 사고 전환을 중심으로 정리한 튜토리얼입니다.

### 📌 이런 분께 추천합니다
- C / C++ 개발 경험이 있는 분
- Rust를 "왜 써야 하는지" 이해하고 싶은 분
- 메모리 안전성, 설계 안정성을 중시하는 엔지니어

### 📌 주의 사항
- ※ 이 문서는 Rust 공식 문서를 재정리한 것이 아니라,
  실제 시스템 개발 경험에서 도출된 설계 관점 정리입니다.

- 이 문서는 **정답** 을 제시하지 않습니다.  
  Rust를 사용할 때 고려해야 할 사고 프레임을 제안합니다.

- 이 튜토리얼은 Rust 공식 문서를 대체하지 않습니다.
- 공식 문서가 **무엇** 을 설명한다면, 이 문서는 **왜 그렇게 설계되었는지** 에 초점을 둡니다.

- **실전 예제는 이후 별도 저장소 또는 확장 챕터로 추가될 수 있습니다.**

- Rust는 모든 보안 문제를 해결하지 않습니다. 다만 특정 종류의 오류를 언어 차원에서 제거합니다.

- 이 저장소는 책 형식보다 실제 학습 중 정리한 노트를 기반으로 구성되었습니다.  
  따라서 다시 체계적으로 정리할 예정 입니다.

- 저의 학습 노트 라고 생각하시고 내용을 참조하시기 바랍니다.
