## 📘 Rust 버전

### 📌 1. 현재 Rust 버전 확인

- PowerShell 또는 CMD에서 실행합니다.
```
rustc --version
cargo --version
rustup --version
```

### 📌 2. Rust 최신 Stable 버전으로 업그레이드
```
rustup update stable
```

- 업데이트한 Stable 버전을 기본으로 설정합니다.
```
rustup default stable
```
- 다시 확인합니다.

```
rustc --version
cargo --version
```
