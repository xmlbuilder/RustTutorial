## 📘 Rust 시작
- Rust를 처음 시작하는 입문자에게 꼭 필요한 **필수 문법 10가지 요약표**.

| 번호 | 문법 요소            | 예시 코드                          | 설명 |
|------|----------------------|------------------------------------|------|
| 1    | 변수 선언            | `let x = 5;`                         | 기본 변수 선언 (불변) |
| 2    | 가변 변수            | `let mut y = 10;`                    | 값 변경 가능한 변수 |
| 3    | 함수 정의            | `fn add(a: i32, b: i32) -> i32 { a+b }` | 함수 선언과 반환 |
| 4    | 구조체               | `struct Point { x: f64, y: f64 }`    | 사용자 정의 타입 |
| 5    | impl 블록            | `impl Point { fn norm(&self) -> f64 { ... }` } | 메서드 정의 |
| 6    | 제네릭               | `fn print<T: Debug>(x: T) { println!("{:?}", x);` } | 타입 일반화 |
| 7    | Option / Result      | `let v: Option<i32> = Some(10);`     | 안전한 값 처리 |
| 8    | Borrow & Mut Borrow  | `fn foo(x: &i32, y: &mut i32) { ... }` | 참조와 가변 참조 |
| 9    | Iterator             | `for x in vec.iter() { println!("{}", x); }` | 반복자 사용 |
| 10   | Trait 구현           | `impl Display for Point { ... }`     | 공통 동작 정의 |

### 📌 요약
- 변수와 함수: `let`, `fn`
- 데이터 구조: `struct`, `impl`
- 제네릭과 Trait: `T`, `impl` `Trait`
- 안전한 값 처리: `Option`, `Result`
- Borrowing: `&`, `&mut`
- 반복자: `iter`, `iter_mut`, `into_iter`
